## Описание программы

Файл: **`system.py`**

Программа — консольное приложение для диагностики операционной системы.

### Что реализовано

| Требование | Как сделано |
|------------|-------------|
| Импорт библиотек | `import os, sys, platform` |
| Переменные | Созданы переменные с результатами методов (`os.name`, `os.getcwd()`, `sys.version`, `platform.system()` и др.) |
| Список | Все значения собраны в список `info_list` |
| Меню | Интерактивное меню с пунктами 0–4 |
| Ввод / вывод | Только через `sys.stdin.readline()` и `sys.stdout.write()` |
| Доступ по индексам | Результаты берутся из `info_list[0]`, `info_list[1]` … |
| Поэтапный вывод | Информация показывается только после выбора пункта меню |
